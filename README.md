## Objective
Analyze student marks and attendance using Python, NumPy, and Pandas.

## Technologies Used
- Python
- NumPy
- Pandas

## Dataset Description
`students.csv` contains 20 fictional student records. Columns: `Student_ID`, `Name`, `Maths`, `Python`, `DBMS`, and `Attendance`.

## Implementation
1. Load the CSV file using Pandas.
2. Validate the required columns.
3. Calculate each student's average marks across Maths, Python, and DBMS.
4. Calculate subject-wise average marks and average attendance.
5. Display the summary in the terminal.

## Key Features
- Loads and validates a CSV dataset.
- Calculates student-wise average marks.
- Summarizes subject averages and attendance.
- Displays a concise terminal summary.

## Final Outcome
The project demonstrates a basic student-data analysis workflow using Python, NumPy, and Pandas.

## Challenges & Learning
Practice in CSV loading, data validation, DataFrame operations, numerical calculations, and organizing project files for GitHub.
